# 验证状态

## 0.2.0-preview

本次变更：名称和 A2 Logo 进入原生工作台、菜单、系统显示名称及安装器品牌；构建配方和源码整理为公开仓库。最终构建和测试结果见 [RELEASE-VALIDATION.md](RELEASE-VALIDATION.md)。

## 继承自 0.1 的验证记录

先前镜像已在 QEMU 的 UEFI Live 环境中启动中文 KDE 桌面；原生工作台已连接系统，工作台把音量从 40% 调到 50% 后，KDE 音量设置读到相同结果；网络面板读到活动连接；无电池虚拟机正确提示未检测到电池。

这些记录不能替代 0.2 的验证。旧测试还出现过长时间运行后虚拟机 GUI 不响应，原因未定位，不能判定真机也存在或不存在此问题。

## 当前限制

- 工作台内 AI、文件摘要、检索、整理、撤销和单位空间均为示例；没有真实模型、文件系统索引、组织身份或策略服务。
- 系统控制在原生壳内运行，浏览器打开网页仅能预览界面。
- 安装器沿用 Debian Calamares。尚未完成安装到空磁盘并重启的全过程测试。
- 真实 Wi-Fi、蓝牙、显卡、音频输出、打印机、休眠、电池和 Secure Boot 未逐项验收。
- 不提供已通过企业、教育或政务安全认证的声明。
- 原型视觉已实现，但尚未完成严格的逐像素设计对照验收。

欢迎提交带设备型号、版本、重现步骤和脱敏日志的 Issue。
