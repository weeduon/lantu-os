# 路线图

## 已有基础

- x86-64 Debian / KDE Live 镜像构建方案。
- 中文输入、字体、Firefox、网络、声音与电源入口。
- 澜图 OS 品牌及澜澜 A2 Logo。
- 可操作工作台与受限原生桥接。

## 下一阶段：安装与桌面可靠性

- 完成空磁盘安装、重启、账户创建和升级测试。
- 按 Intel / AMD 台式机及笔记本建立硬件兼容清单。
- 测试输入法、休眠、蓝牙、Wi-Fi、打印及日常办公格式。
- 改进系统状态刷新及错误提示，增加自动化原生集成测试。

## AI 实用化

- 配置本地模型或兼容 API；提供连接测试、清晰错误与取消操作。
- 用户选择目录后索引真实文档；记录来源与访问范围。
- 对摘要和问答提供可定位的引用。
- 文件操作先预览、检查冲突，再确认执行，并可恢复。

## 组织场景

- 统一身份、设备策略、审计、内网模型与更新渠道。
- 为学校机房、企业办公等形成独立部署配置。
- 根据实际部署要求开展安全和兼容性验证。
